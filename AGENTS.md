# CWS — инструкции продукта

Папка продукта относительно этого файла: `..`. Состояние и решения — её README.md, история — log.md. README репозитория кода не заменяет README продукта.

Перед работой прочитай README продукта, `~/.codex/cws-agents/_common.md`, `common/engineering.md` и `common/runtime.md` через тот же якорь. Для этапа используй `pipeline-command.md` и нужный раздел PIPELINE.md. Старые CLAUDE.md и соседние продукты не задают текущие правила.

Если ты субагент, исполни только блок из брифа, не создавай вложенных агентов и верни статус оркестратору. Оркестратор ведёт README продукта, проверяет результат и сам продолжает разрешённую работу. Для полного CWS-конвейера он делегирует независимые блоки по `common/runtime.md`; для одной небольшой правки отдельный агент не нужен.

Сохраняй решения Аны и границы поручения. Подтверждённые дефекты исправляй самостоятельно с проверкой; новые продуктовые решения и публикация — по действующим правилам сетки. Не переспрашивай уже полученное разрешение. Оркестратор задаёт вопросы через штатную карточку с вариантами ответа по `common/runtime.md`, раздел «Вопросы Ане»; субагенты передают вопросы ему. Список вариантов в сообщении карточку не заменяет.
